Super Mario Odyssey — private file check

Check your own base 1.0.0 NSP and 1.4.1 update NSP on iPhone. This reads only each file’s PFS0 header and small file index, not the gigabytes of game content.

Privacy first

No account, network requests, uploading, analytics, or server storage. Your files stay on your device. Do not select or share `prod.keys` here. This page does not need console keys.

Expected title ID: 0100000000010000 Expected update title ID: 0100000000010800
Select both NSPs from the Files app to begin.
What passing means

Matching names, versions, file-index structure, and recognizable NCA entries. It does not verify game encryption, keys, Nintendo signatures, GPU support, or that an IPA can be built or run.

A real native game IPA still needs a secure private macOS/Xcode builder and code-signing setup. Those services are not part of this page. Do not publish game files or keys to GitHub or Actions.
